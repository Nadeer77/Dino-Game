# 🦖 Dino Game

A 2D endless runner game developed using **Unity and C#**, recreating the classic Chrome Dinosaur Game with its original gameplay mechanics.

## 🎮 Project Overview

Dino Game is a recreation of the classic offline dinosaur game found in Google Chrome. Players control a running dinosaur, avoid obstacles, and try to achieve the highest possible score. The game becomes progressively faster as the run continues.

## ✨ Features

- **Endless Running:** The dinosaur runs automatically throughout the game.
- **Jumping:** Jump over ground obstacles such as cacti.
- **Ducking:** Duck to avoid incoming flying obstacles.
- **Obstacle Spawning:** Obstacles appear as the player progresses.
- **Increasing Difficulty:** Game speed increases over time.
- **Score System:** Tracks the player's score during gameplay.
- **Collision Detection:** Detects collisions with obstacles and triggers Game Over.
- **Restart System:** Allows players to restart and try again after Game Over.

## 🕹️ How to Play

1. Start the game to begin running automatically.
2. Press **Space** or **Up Arrow** to jump over obstacles.
3. Press **Down Arrow** to duck under flying obstacles.
4. Avoid colliding with obstacles for as long as possible.
5. Try to achieve the highest score.
